EXAMLAB V7 — NÚT SÁNG/TỐI DẠNG CHỮ, KHÔNG SVG

1. Giải nén và upload toàn bộ nội dung ZIP vào THƯ MỤC GỐC repository GitHub Pages.
2. Ghi đè 6 file HTML và js/app.js.
3. Upload CSS MỚI: css/mode-switch-v7.css (rất quan trọng).
4. Không cần upload js/theme.js hoặc css/theme.css nữa: bản V7 không gọi các file này.
5. Có thể xóa js/theme.js, css/theme.css CŨ trên GitHub sau khi đã upload xong.
6. KHÔNG xóa/chỉnh file supabase-config.js; không thay URL hoặc key của dự án.
7. Mở trang bằng Ctrl + Shift + R hoặc tab ẩn danh nếu Chrome còn cache.

Nút mới hiển thị SÁNG hoặc TỐI, có chấm chỉ trạng thái.
Bấm nút sẽ chuyển ngay chế độ, lưu localStorage với key examlab.theme.
Cơ chế bấm nằm trực tiếp trên nút HTML, không phụ thuộc JS của thư viện.

LƯU Ý: không xóa thư mục css/ và js/ do các chức năng khác vẫn cần.
